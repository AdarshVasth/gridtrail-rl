# Map and benchmark provenance

`maps.json` contains three original hand-authored rectangular mazes. Characters: S=start, G=goal, .=traversable floor, #=wall. No external game, geospatial data, personal information or image asset is used. These maps and generated benchmark results are covered by the repository MIT license.

`benchmark.json` is generated by real local runs of `python evaluate.py`. It contains one row per map/training seed with greedy success, greedy steps/reward, BFS shortest steps, random success fraction and random mean capped steps. Repeated random-baseline values across training seeds refer to the same 100 evaluation trials; do not count them as extra independent observations.
